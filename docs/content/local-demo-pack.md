## Included learning material

| Level | Activity | Content type |
| --- | --- | --- |
| A1 | Introduce yourself | Speaking language + MCQ |
| A2 | Make a simple plan | `be going to` grammar + MCQ |
| B1 | A library for everyone | Reading passage + MCQ |
| B2 | Build a clear argument | Linking-word grammar + MCQ |
| C1 | Hear the nuance | Listening transcript + MCQ |
| C2 | Interpret precise language | Listening transcript + MCQ |

Vocabulary includes three original CEFR-tagged entries at every level, with IPA,
Vietnamese meaning and an English example.

## Listening rule

The two listening activities use browser speech synthesis from their local transcript.
They are labelled as browser-voice demos in the UI and must be replaced with reviewed,
licensed recording URLs before a production release. No third-party audio is stored or
redistributed by this pack.
